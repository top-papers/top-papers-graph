# Первый вклад слушателя

Цель первого вклада — пройти полный цикл open-source работы на небольшой безопасной задаче.

## Маршрут на 60–90 минут

1. Запустите офлайн-демо и убедитесь, что проект работает.
2. Выберите один артефакт: документация, тест, научная проверка или маленькое исправление.
3. Опишите ожидаемый результат в issue или комментарии к задаче.
4. Сделайте изменение в отдельной ветке.
5. Проверьте его по инструкции или тестом.
6. Откройте pull request и ответьте на ревью.

## Безопасные первые задачи

### Исследователь / эксперт

- заполнить один шаблон в `data/experts/trajectories/`;
- проверить 10–20 связей и описать причины accept/reject;
- найти утверждение без достаточного evidence;
- уточнить temporal correction с указанием страницы и источника.

### Разработчик

- воспроизвести issue и добавить regression test;
- улучшить сообщение об ошибке;
- проверить команду quickstart на чистом окружении;
- добавить небольшой parser fallback или validation rule.

### Документация / координация

- исправить шаг, который нельзя повторить;
- добавить минимальный пример;
- связать разрозненные инструкции;
- оформить issue для задачи, которой сможет заняться новичок.

## Формула хорошего вклада

```text
контекст + маленькое изменение + способ проверки + объяснение ограничений
```

Не нужно заранее знать весь стек. Сначала доведите один небольшой вклад до merge, затем берите более сложную роль.
