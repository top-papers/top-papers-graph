# Учебные notebooks

Здесь хранятся только канонические версии блокнотов. Сохранённые outputs и execution counts удалены: блокнот должен воспроизводить результат при повторном запуске, а не хранить состояние чужой среды.

## Маршрут курса

1. `task1_reasoning_trajectories_form_colab.ipynb` — траектория научного рассуждения.
2. `task2_temporal_graph_validation_colab.ipynb` — проверка темпорального графа.
3. `task3_multimodal_temporal_hypothesis_generation_colab.ipynb` — генерация гипотез.
4. `task3_dual_local_models_blind_ab_colab.ipynb` — слепое сравнение двух вариантов.
5. `task3_ab_testset_authoring_colab.ipynb` — подготовка кейсов для benchmark.
6. `top_papers_graph_task3_hf_benchmark_colab.ipynb` — публикация benchmark.

Дополнительные варианты предназначены для офлайн/Kaggle запуска и фасилитации экспертной сессии. Инструкции: [`docs/course/tasks/`](../docs/course/tasks/README.md).
