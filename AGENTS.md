# AGENTS.md — руководство для ИИ-агентов

Этот репозиторий — одновременно **открытый учебный курс** (12 недель) и
**исследовательский инструмент** для анализа научной литературы. Агент,
работающий здесь, должен понимать обе роли.

## Быстрый старт

```bash
./scripts/bootstrap.sh                  # Windows: .\scripts\bootstrap.ps1
top-papers-graph demo-run --llm-provider mock   # офлайн-демо без API-ключей
top-papers-graph smoke-all              # проверка целостности
```

Демо работает **офлайн** через mock-провайдер. Это основной сценарий для
проверки изменений: он не требует ключей и не тратит деньги.

## Карта репозитория

| Путь | Назначение |
|---|---|
| `course/` | программа курса: 12 недельных модулей, руководства |
| `docs/course/syllabus.md` | **точка входа** в программу, связывает все материалы |
| `docs/course/syllabus.json` | машиночитаемая программа |
| `docs/course/tasks/` | инструкции к заданиям (Task 2, Task 3, A/B) |
| `docs/course/experts/` | экспертный трек: разметка, ревью, контроль качества |
| `notebooks/` | канонические запускаемые примеры (Colab) |
| `src/scireason/` | основной код: ingest, граф, темпоральность, верификация |
| `scripts/` | bootstrap, валидаторы, вспомогательные инструменты |
| `experiments/` | эксперименты, включая VLM A/B и fine-tuning |

## Правила для агента

### Что можно делать свободно

- Читать любые файлы, запускать офлайн-демо и тесты.
- Улучшать документацию курса, исправлять битые ссылки.
- Добавлять тесты и валидаторы.
- Предлагать изменения через pull request.

### Что требует осторожности

- **Не выдумывайте содержание курса.** Каждое утверждение о научной теме
  должно опираться на файл в репозитории или внешний источник со ссылкой.
- **Не вызывайте платные LLM-провайдеры** без явного запроса. По умолчанию
  используйте `--llm-provider mock`.
- **Не удаляйте файлы курса.** Если материал кажется лишним, предложите
  перемещение или архивацию отдельным PR.
- **Не меняйте данные в `data/`** без понимания происхождения: см.
  `LICENSE_SCOPE.md` и схемы provenance.

### Стиль изменений

- Учебные материалы — на русском языке (курс читается на русском).
- Код, имена переменных и комментарии — на английском.
- Сохраняйте SPDX-заголовки в начале файлов:
  ```
  <!-- SPDX-FileCopyrightText: 2026 top-papers-graph contributors -->
  <!-- SPDX-License-Identifier: GPL-3.0-or-later -->
  ```

## Проверка перед коммитом

```bash
# 1. Офлайн-демо проходит
top-papers-graph demo-run --llm-provider mock

# 2. Smoke-тесты проходят
top-papers-graph smoke-all

# 3. Валидация экспертных артефактов (если меняли их)
python3 scripts/ci/validate_expert_artifacts.py

# 4. Относительные ссылки в документации курса разрешаются
#    (проверяется автоматически в CI)
```

## Типичные задачи агента

| Задача | Как подойти |
|---|---|
| «Улучши документацию курса» | Начните с `docs/course/syllabus.md`, проверьте связность ссылок |
| «Добавь задание» | Посмотрите формат в `docs/course/tasks/`, добавьте запись в индекс и в syllabus.json |
| «Проверь, чего не хватает» | Запустите OCA: `oca scan .` — даст оценку и план |
| «Исправь пайплайн» | Начните с офлайн-демо, затем `src/scireason/` |
| «Разметь данные» | Инструкции в `docs/course/experts/docs_experts/` |
