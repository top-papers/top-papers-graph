# Week 06 — Встреча синка (60 минут)
**Тема недели:** Temporal sanity v1

## Подготовка (до встречи, 10–20 минут)
- Экспертам: 1 graph review (time/conditions)
- Отметить 2 конфликта

## Цели встречи (что должно получиться к концу)
- Граф не смешивает периоды/условия
- Есть правила time_scope
- Список конфликтов

## План встречи (тайминг, 60 минут)
- 00:00–10:00 статус temporal store
- 10:00–25:00 разбор конфликтов
- 25:00–40:00 правила time_scope
- 40:00–55:00 обновление шаблонов
- 55:00–60:00 задачи недели 7

## Решения, которые нужно принять на встрече
- Какие артефакты считаем “готовыми” на этой неделе (DoD)?
- Какие 1–3 блокера снять до следующего синка?
- Что отправляем в Parking Lot?

## Action items (после встречи)
- Сдать 2 temporal-focused reviews
- Обновить глоссарий условий
